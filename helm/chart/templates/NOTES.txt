RavenDB Operator {{ .Chart.AppVersion }} installed in namespace "{{ .Release.Namespace }}".

This chart installs only the operator (controller, CRD, RBAC, webhooks).
To run a RavenDB cluster, install the ravendb-cluster chart in a workload namespace:

  helm install my-cluster ravendb-operator/ravendb-cluster \
    -n ravendb --create-namespace \
    -f my-values.yaml

Verify the operator:

  kubectl get pods -n {{ .Release.Namespace }}
  kubectl get crd ravendbclusters.ravendb.ravendb.io

Documentation:

  - Cluster chart:   https://github.com/ravendb/ravendb-operator/blob/main/helm/cluster-chart/README.md
  - Examples:        https://github.com/ravendb/ravendb-operator/tree/main/examples
